# Changelog

## [0.1.0 — Fedora](https://github.com/Sami7ma/ORBIT/releases/tag/v0.1.0) · 2026-11-26

First packaged Fedora release, tested on Fedora 44 KDE on x86_64.

- World clocks with day-progress rings, date differences and timezone-aware offsets.
- Searchable, reorderable city list with saved preferences and recovery for damaged data.
- Optional weather badges and forecasts, explicit Local weather location, and Celsius/Fahrenheit display.
- Compact clock details, resizable viewport, horizontal scrolling and multiple rows.
- Window lock and persistent always-on-top controls, including KDE Wayland integration.
- Customizable appearance, clock scale and time format.

The release includes an unsigned RPM and SHA-256 checksum. Windows installers build in CI; native Windows validation remains pending. See [verification](docs/testing.md) for the tested scope and known limitations.
